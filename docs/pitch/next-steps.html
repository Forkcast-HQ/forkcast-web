Where we are, and what’s next.

Where we are now (done)

  • Working, investor-ready demo (live: seymurhh.github.io/forkcast-live) — accounts, onboarding, BMI/TDEE/macros, Fit-Score discovery + map, dashboard, photo logging.
  • Strategy package — business plan, financial model, system architecture, research dossier (private).
  • Private source repo + one-command deploy.

What we do not have yet: real users, real restaurants, a pitch deck distributed, or external validation. That’s the gap the next steps close.

The next step — single focus for ~4 weeks

Turn the demo into proof. Get evidence diners want this and restaurants will play — before writing more code or raising.

  • 20 user interviews (Boston/Cambridge, Harvard network first) → one-page “what we heard.”
  • Demand signal: add a real waitlist to the live site; drive ~200 signups via TikTok/IG + campus channels.
  • 5–10 restaurant conversations in one dense neighborhood → ≥3 verbal “I’d try it.”
  • Build the pitch deck (10–13 slides) from the business plan. drafted

Then — next ~90 days (in order)

  • Beachhead data layer — real chain nutrition (USDA + Nutritionix) for ~50 real Boston restaurants.
  • MVP backend — real auth + database; turn on real Claude photo analysis (SSR host).
  • First 10 restaurants + 100 active users in one neighborhood; track D30 retention (>35%) and CAC.
  • Apply for non-dilutive grants — NIH/NIDDK & USDA-NIFA SBIR (verify post-Apr-2026 solicitation dates).
